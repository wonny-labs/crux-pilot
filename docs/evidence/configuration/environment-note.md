# Validation environment correction

The first Linux build-tool run executed 293 methods and reported two failures
plus one error. All three arose when the existing execution source checker read
an AppleDouble `._execution.h` generated by the initial macOS tar stream.
The eight-byte header `0005160700020000` identified those metadata files. They
were not repository source files. Only those generated metadata files were
removed from the disposable `/tmp/crux` snapshot, and subsequent copying disabled
AppleDouble generation (`COPYFILE_DISABLE=1`, `tar --no-xattrs`). No product or
checker behavior was changed to conceal the failure. The final run is retained
separately. Initial debug/sanitizer regressions passed 78/78 each; final affected
Configuration tests and native_sim were rerun after the added mixed-key case.

A preliminary setup command also stopped on missing CMake in PATH, corrected by
using the existing cached tool path; another stopped on Git snapshot ownership,
corrected only inside the disposable container with an explicit safe.directory.
These were environment setup failures, not reported as test passes.

The first full static-analysis script reached the Configuration group after
passing the unchanged Time/controller/networking groups, then reported ten owned
warnings as errors: enum-zero output initialization, prechecked strcpy, and
swappable private metadata/fault-control parameters. Valid enum initialization,
length-checked memcpy, grouped private record metadata and typed fault options
remove these warnings without changing the public contract or suppressing checks.
Final affected analysis, Host tests/consumers and native_sim were rerun; independent
Reviewer and Challenger re-reviewed this delta. These original diagnostics remain
in the pre-correction log.

A later redundant full Host rerun stopped at unchanged
`Netif.ClearsBytesOfAbsentAddressAndReportsUnknownCarrier`. Its test child was a
zombie while CTest waited in epoll. INT/TERM did not finish CTest; the owned
runner was killed and that run is not a pass. Root cause remains unresolved.
Earlier complete debug/sanitizer runs passed 78/78. Final affected Configuration
cases passed 2/2 in both presets under explicit 15-second test/60-second process
limits; independent consumer and native_sim checks also passed. This observation
must remain visible, and latest hosted CI must be checked before merge.
