**Goal:** Deliver the approved minimal UART-backed Serial capability for Issue #27.
**Architecture:** component-owned common validation/lifetime plus private Linux
TTY and Zephyr IRQ UART ports, public `crux::serial`, separate native composition.
**Tech Stack:** C17/C++17; existing CMake/GoogleTest/CTest; Zephyr 4.4.0
`684c9e8f32e4373a21098559f748f06915f950c9`; ztest/UART emulator; EVKB cross-build.
**Spec:** [proposed Serial design](../specs/2026-10-24-serial-design.md).

## Global constraints

- Software implementation is approved for the linked contract. Reconcile any
  material contract changes with the user before adopting them.
- Start from current main, preserve completed Thread/Sync structure and other work.
- No public native types/private includes, new OSAL, production partition or native
  dependency exception. Serial public target needs Base, not Thread or Sync.
- No hardware, PR merge or Issue closure. Produce a Draft PR and physical proposal.
- Initial profile: logical port 0, 115200 8N1, 256-byte Zephyr RX/TX rings; Host
  staging chunks <=256 bytes with separate kernel TTY queues. Other approved requests
  get mapping/rejection evidence, not untested electrical-support claims.
- Develop with affected tests; final required CI on fixed HEAD. No long stress or
  elaborate runner. Baseline/source/build claims require actual inspected outputs.

## Review focus

- Poll/finite timeout must include metadata admission and cannot commit after timeout.
- Native callbacks must not access caller storage or a retired/reused instance.
- Short success/queued TX must not be mistaken for full delivery or successful drain.
- Aliases/console/logging/CSI ownership must not be bypassed by logical IDs.
- Native errors, overflow, EOF-like zero reads and failed cleanup must stay observable.

## Proposed file map

- `components/serial/include/crux/serial.h`: approved declarations only.
- `components/serial/src/serial.c`, `serial_port.h`: validation, handles, lifecycle
  admission and private port contract. Define a single deadline at operation entry.
- `components/serial/ports/linux/serial_host.c`, `serial_host.h`: actual TTY port
  and private immutable bind-before-use composition interface.
- `components/serial/ports/zephyr/serial_zephyr.c`, `CMakeLists.txt`: IRQ/native
  resource ownership, ring buffers and static callback lifetime.
- Component `CMakeLists.txt`, root CMake and `zephyr/{CMakeLists.txt,Kconfig}`:
  explicit provider selection and component-owned resource settings.
- `tests/serial/`, `tests/serial/zephyr/`: focused portable and native port cases.
- `samples/serial/controller.c`: public-only small controller transaction; no Shell
  migration. `tests/serial_consumer/`: separately authored C17/C++17 consumer with
  native bootstrap/peer kept outside its portable object.
- `tests/serial_consumer/zephyr/`: public consumer + UART emulator/EVKB binding.
- Existing native-interface/build guards, CI workflows and `scripts/test-serial.sh`:
  add the new owned sources/usage target to existing enforcement and runner patterns.
- Adopted Serial contract and validation record, tests guide: supported behaviour,
  acceptance map, actual outcomes, limits and separate physical proposal.
