**Spec:** [Approved contract](../specs/2026-10-24-logging-design.md), approved by the user on 24 October 2026 at proposal `ed6f3bd`.

## Global Constraints

- `crux_log_write(level, const char *tag, const char *text)` and `crux_log_set_level(level)` return existing `crux_status_t`; public `<crux/logging.h>` / `crux::logging`, Base only.
- OFF=0, ERROR=1, WARN=2, INFO=3, DEBUG=4; default INFO. OFF valid only as setter; validated filtered calls OK. Threshold sampled once; invalid setter preserves old value.
- Tag 1..24 ASCII alphanumeric/underscore/hyphen/dot; text 0..256 bytes, no CR/LF, both NUL-terminated and borrowed only until return. Oversize OUT_OF_RANGE, no silent truncation.
- OK = valid call handled or native attempt, never queue/wire acknowledgement. Preserve native aggregate drop reporting; no per-call drop counter promises.
- Task context after startup only; ISR/pre-kernel NOT_SUPPORTED. Known backend unready NOT_READY, known Host failure IO; partial Host output may precede IO.
- Host synchronous native serialization/I/O may block. Zephyr deferred, native worker, no capacity wait, drop-new. No whole-call WCET bound.
- Initial UART TEXT backend only; explicit single chosen UART, native_sim dedicated emulator / EVKB LPUART1, separate Serial LPUART3. Build rejects missing/unsupported/conflicting selections; no Serial sharing or public Serial dependency.
- Native log buffer4096, native stack2048/priority14 initial fixture, not product sizing. Existing M3 images unchanged. No hardware, merge or #29 closure.
- Use affected checks during work; one full applicable hosted CI at final stable HEAD. No redundant unrelated baseline replay: merged main6a58145 matches the software-qualified PR58 source tree.

## Review Focus

- Deferred buffers must be copied before return even when caller overwrites stack text/tag; prove via actual native backend.
- Native queue loss may follow OK; verify real drop-new reporting rather than inventing acceptance feedback.
- Resolved config must preserve all four severities and single common filter, with no hidden native filter or extra backend.
- UART Console/Shell/Serial and known child/native owners must fail builds on collision, including independently enabled Serial.
- Host IO failure may leave a partial record; serialize concurrent successful records and avoid automatic retries.
